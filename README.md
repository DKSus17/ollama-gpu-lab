# Ollama GPU Lab

## About

This repository documents my personal learning and experimentation with open-source large language models (LLMs), local inference, and GPU cloud infrastructure.

## Goals

- Learn how to deploy and run LLMs using Ollama.
- Evaluate quantized models and their memory requirements.
- Explore inference performance on high-memory AMD GPUs.
- Document setup steps, configuration, and reproducible experiments.
- Share useful notes with other developers and open-source AI enthusiasts.

## Planned experiments

1. Set up an AMD GPU cloud environment.
2. Install and configure Ollama or a compatible inference runtime.
3. Test suitable open-source language models and quantization formats.
4. Record model size, VRAM usage, generation speed, and setup requirements.
5. Publish results and troubleshooting notes.

## Intended hardware

I am interested in evaluating AMD Instinct GPUs, particularly the MI300X with 192 GB of HBM memory, for running larger open-source language models.

The experiments will depend on access to suitable hardware and cloud credits. Results will be added after testing; no benchmark results are claimed yet.
